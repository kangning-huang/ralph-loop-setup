# Claude Code Configuration

This file configures Claude Code skills for the Ralph Wiggum Loop project.

## Skills

### /ralph-loop

Sets up a Ralph Wiggum Loop for automated task implementation.

**Usage**: Type `/ralph-loop` in Claude Code to start the setup wizard.

**What it does**:
- Helps you create a structured todo list from existing files or from scratch
- Breaks down your project into implementable tasks
- Generates a properly formatted `todolist.json`
- Sets up progress tracking

**When to use**:
- Starting a new project with many tasks
- Converting existing todo lists/notes into automated workflow
- Breaking down a large feature into smaller tasks

---

## About Ralph Wiggum Loop

An automated task implementation system that runs Claude Code in a loop to complete your project todo list, one task at a time.

See [README.md](./README.md) for full documentation.
